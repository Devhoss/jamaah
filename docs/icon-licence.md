# Icons — source and licence

The stroke icons in `lib/src/features/components/line_icon.dart` are path data from
**Lucide** (https://lucide.dev, github.com/lucide-icons/lucide), as used by the Horizon
design prototype (`docs/design-brief/horizon-reference/Horizon.dc.html`).

Lucide is under the **ISC licence**; the icons it derives from Feather (among those used
here: check, chevron-down, chevron-right, info) are under **MIT**. The full licence text,
copied unchanged from the Lucide repository on 2026-10-15, is in
`docs/licences/lucide-LICENSE.txt`. Both licences ask that the notice travels with the
icons, so an in-app licences page must include it before release.

Only a handful of shapes are copied, as path strings; no Lucide package is a dependency.
