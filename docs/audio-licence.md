Full recordings are read from Flutter assets by the native Android Adhan
service. Fajr-specific recordings appear only in the Fajr recording picker.
The five short MP3s are also copied byte-for-byte into Android `res/raw` so
notification channel playback matches the preview. Short Adhan channel IDs
include each clip and tone version because Android fixes channel sounds when
the channel is created.

`assets/audio/chime/reminder_chime.wav` is a separate app-generated two-note
reminder chime. It was generated by `tool/generate_reminder_chime.dart`; no
third-party recording is used for it.

When the source or licence for a supplied recording is confirmed, add its URL,
creator, licence text and any required attribution to this table before a
public release.
